# Security policy

VeliraPay is a live payment service that holds and moves real merchants' and customers' money. It runs no bug bounty, capture-the-flag challenge or practice environment, and nobody is authorized to probe, scan or exploit velirapay.com, its API or its MCP server. The [Terms of Service](https://velirapay.com/terms) forbid probing the service, and accounts that do are suspended automatically.

## Reporting a vulnerability

To report a vulnerability you came across, in the service or in one of these libraries, email contact@velirapay.com.

Please don't open a public issue for it, and leave API keys, webhook signing secrets and customers' details out of your message.
