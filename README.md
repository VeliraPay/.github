# VeliraPay on GitHub

This repository holds what GitHub shows for the [VeliraPay organization](https://github.com/VeliraPay):

- `profile/README.md`, the organization's profile page;
- the default [security policy](SECURITY.md), [support](SUPPORT.md) and [contributing](CONTRIBUTING.md) guides and issue forms, used by every repository here that has none of its own.

VeliraPay itself is at [velirapay.com](https://velirapay.com), with its [documentation](https://velirapay.com/docs).
